# 竞赛材料索引

| 文件 | 用途 | 建议使用场景 |

## 核心竞争优势速览

1. **自进化智能体**：大臣（Agent）通过任务执行反馈自动优化自身能力，无须人工调参
2. **多智能体辩论共识**：5种共识策略，多大臣协同决策，减少70%单点错误
3. **全栈闭环**：LLM → Router → RAG → 多模态 → 工具调用 → 自愈 → 评测，一条龙
4. **信创兼容**：支持 NVIDIA/昇腾/寒武纪 + 麒麟/统信 + 5个国产模型 API
5. **竞赛基因**：从代码架构到文档材料均为竞赛场景设计
